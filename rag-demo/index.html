THE DIFFERENCE

结构不是 metadata。
它决定模型下一步可以怎样读。

传统 RAG 的 chunk 主要是召回单位；WisePen 将命中的 chunk 还原到资料中的完整 Section，并把标题树、精确来源和跨文档关系变成可操作的阅读选项。模型不必在一次回答里猜完整上下文。

1. Hybrid locateDense + BM25 只负责从候选资料中找到可靠入口。
2. Section read命中回源到不跨章节的阅读块，带标题路径与精确 locator。
3. Graph expand需要跨资料时，再沿证据支撑的关系展开，而不是先构建全库大图。

四种路线，差在命中之后

它们可以共享混合召回；真正的区别是如何保住上下文、如何让 Agent 主动延伸阅读，以及图关系放在什么位置发挥价值。

AGENT TOOLING

模型面对的是三步清晰的阅读动作

01 / LOCATE

找到值得开始读的 Section

混合召回只筛入口。返回命中理由、Section 预览和来源，而不是把零散 chunk 直接当最终上下文。

knowledge_navigate_locate
02 / SECTIONS

沿标题树补足文档内推理

读取完整 Section 内容，并在当前节点看到父级、前后同级和子级，让模型按资料原本的组织方式继续。

knowledge_navigate_sections
03 / EXPAND

跨文档追踪概念与来源

只在需要时展开实体、引用、依赖等带证据的关系。关系不是替代原文，而是下一次阅读的可靠指针。

knowledge_navigate_expand
