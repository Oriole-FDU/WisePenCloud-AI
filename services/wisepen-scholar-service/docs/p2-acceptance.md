# P2 离线富化验收

离线实现已完成，真实全量扫描仍在运行；此记录不将代码或样本验证视为全库完成。

选择性扫描本地 papers/tldrs gzip，只保留与本地 arXiv 基础论文精确关联的事实。明确 arXiv 身份优先，只有没有 arXiv 身份且 DOI 唯一时才通过 DOI 关联。冲突记录为诊断，不按标题猜测或覆盖另一篇论文。TLDR 只选择声明的 `tldr@v2.0.0`。

每个分片以完整事务读取到 EOF 后确认完成；异常回滚该分片，重跑重新读取。输入清单、大小和修改时间用于拒绝替换后的续跑。全部分片完整后才更新文档投影与 pending，并沿用既有 ES 文档身份增量发布。

已验证：

- 14 项受影响 ETL 测试通过，覆盖 gzip/JSON 失败、重放、冲突、DOI-only、model 选择、0/false/空 TLDR、其他来源 metadata 保留及重复投影。
- 真实 ES 小样本通过离线导入、投影、版本发布、读取与 TLDR 文本检索；重复投影不产生变化，测试索引已删除。该样本依据已保存的 API 实验事实构造，证明映射和发布路径，不能证明完整 release 扫描。
- arXiv 完整基础库已发布 3,224,542 篇；S2 全量导入独立于 HTTP 进程，在 `.runtime/import-s2.log` 记录分片进度。

仍待验证：现有 90 个 gzip 全量 EOF/CRC/JSON 完整性、全量扫描与关联统计、最终富化发布及 DuckDB/ES 抽样一致性。
