# P2 离线富化验收

离线实现已完成，90 个分片均已读到 EOF；两次合并论文信息的尝试因内存不足失败并回滚，修复后正在运行真实合并任务。此记录不将代码或样本验证视为全库完成。本文的“投影”是将已筛选的
S2 引用数、TLDR 等合并进本地论文文档，不是重新读取原始压缩文件，也不是增量同步。

选择性扫描本地 papers/tldrs gzip，只保留与本地 arXiv 基础论文精确关联的事实。明确 arXiv 身份优先，只有没有 arXiv 身份且 DOI
唯一时才通过 DOI 关联。冲突记录为诊断，不按标题猜测或覆盖另一篇论文。TLDR 只选择声明的 `tldr@v2.0.0`。

每个分片以完整事务读取到 EOF 后确认完成；异常回滚该分片，重跑重新读取。输入清单、大小和修改时间用于拒绝替换后的续跑。全部分片完整后才更新文档投影与
pending，并沿用既有 ES 文档身份增量发布。

已验证：

- 合并与 S2 差分的 21 项定向测试通过，覆盖 gzip/JSON 失败、重放、冲突、DOI-only、model 选择、0/false/空 TLDR、其他来源 metadata
  保留及重复投影。
- 真实 ES 小样本通过离线导入、投影、版本发布、读取与 TLDR 文本检索；重复投影不产生变化，测试索引已删除。该样本依据已保存的 API
  实验事实构造，证明映射和发布路径，不能证明完整 release 扫描。
- arXiv 完整基础库已发布 3,224,542 篇；S2 全量导入独立于 HTTP 进程，在 `.runtime/import-s2.log` 记录分片进度。

当前真实数据库确认：papers 60 个分片，共扫描 239,337,671 条、保留 3,276,233 条；tldrs 30 个分片，共扫描 67,489,903 条、保留
1,185,284 条；未完成分片为 0。失败投影未留下 pending，基础库仍为 3,224,542 篇且保持原已发布状态。分片不需重扫。

仍待验证：有界投影完成、完整关联/冲突统计、最终富化发布及 DuckDB/ES 抽样一致性和重复运行。

全量合并改为分批生成文档，再分批写入保留四列及主键的替换表，在同一事务内换名并提交待发布集合，避免全量 JSON UPDATE
让旧行版本持续占用事务 undo。差分仍只更新实际受影响的论文。真实任务通过[本地看板](offline-dashboard.md)
记录各阶段、未提交数量及实际退出码；任务名称为“合并本地 S2 信息 → 更新论文检索索引”。
