# 面向 Agent 的可编排 RAG 工具链

## 是什么

传统 RAG 把 RAG 视为完成任务的整套平台，模型只能机械执行“检索—反思—生成”的固定链路。我们把 RAG 视为 **Agent 平台的一组知识工具**：Agent 掌握任务主导权，可在推理和行动过程中随时检索、阅读、探索与补证。

## 为什么

复杂任务不是一次问答。Agent 往往需要“先 RAG 获取线索 → 调用其他工具分析或行动 → 根据新结果再次 RAG → 补齐证据并继续执行”。只有将 RAG 工具化，才能让知识获取穿插在任务全过程中，形成持续的 **规划—检索—行动—验证** 闭环。

## 怎么做

我们以 **Section 为主要知识单元**，建设文档与图谱双基座：文档侧通过 **父子分块、Contextualize、Dense + BM25 混合检索、标题树拓扑与邻域阅读**，实现“小块精准命中、大块完整阅读”；图谱侧通过 **Low-level 实体检索、High-level 关系检索和 Hybrid 融合检索**，实现跨章节、多跳关系发现与原文反查。

```text

                   ┌──────────────────────┐

                   └──────────┬───────────┘
                              │
             ┌────────────────┴────────────────┐
             ▼                                 ▼
      文档混合检索工具                    图谱检索工具
      Dense + BM25                  Low / High / Hybrid
             │                                 │
      子块命中 → Section 聚合            实体/关系召回 → 多跳扩展
             │                                 │
      动态父块 + 标题树邻域              Neo4j 拓扑 → 原文反查

                              ▼
                 去重 + Rerank + 证据组装
                 原文 / Section / 页码 / 拓扑
                              │
                              ▼
        回答或行动 → 调用其他工具 → 再次 RAG 补证
                              └────────► 持续闭环
```

最终支持四类 Agent 闭环：**事实核验**（检索—回源—验证）、**概念探索**（实体—拓扑—原文）、**主题推理**（关系—多跳—综合）和 **任务执行**（RAG—工具行动—再 RAG）。
