# Daily Works

这个目录就是日记。

定位很简单：

- 面向自己
- 记录当天实际完成了什么
- 可以写得轻松一点
- 但必须把完成项、影响面、遗留项写清楚

适合放这里的内容：

- 当天完成的开发工作
- 当天完成的优化和重构
- 当天完成的文档收敛
- 当天做过的重要判断和取舍

不适合放这里的内容：

- 长期稳定规范：放 `docs/team/`
- 当前工具契约：放 `docs/tools/`
- 已完成且需要长期追溯的关键变更：放 `docs/important/`
- 即将实行的事项：放 `docs/todo/`
- 短期不做但有价值的规划：放 `docs/plans/`
- 单次任务 AI 接手文档：放 `docs/ai_assist/`
