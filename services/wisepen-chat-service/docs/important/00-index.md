# 重要变更索引

本目录用于保存已经落地、影响核心行为、需要长期追溯的实现说明。

适合放这里的内容：

- 核心工具链收敛或重构
- 返回值契约、缓存协议、跨工具引用协议变更
- 对多个工具或多个共享组件同时生效的行为调整
- 需要说明背景、影响面、预期效果和迁移含义的完成项

不适合放这里的内容：

- 即将开始但尚未落地的事项：放 `todo/`
- 有价值但短期不做的规划：放 `plans/`
- 单次对话的接手记录：放 `ai_assist/`
