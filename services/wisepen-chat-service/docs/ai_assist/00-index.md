# AI Assist 目录说明

本目录只用于**单次任务**的 AI 接手文档。

规则：

- 文件名必须精确描述任务，例如：
  - `2026-06-19-web-fetch-cache-review-fixes.md`
  - `2026-06-19-core-reading-tools-doc-sync.md`
- 不允许使用笼统的 `README.md` 作为任务承接文档。
- 已经完成且具长期价值的内容，应迁移到 `docs/important/`、`docs/team/` 或对应工具文档。
- 已经完成且只保留短期历史价值的任务，应删除，不长期堆积。

当前目录保留为占位与规则说明；没有活动中的接手任务文件时，这是唯一应保留的文件。
