# 计划书索引

本目录只放尚未实现、但仍能指导后续开发的计划。

已实现的计划不应留在这里；实现完成后，把稳定规则合并进 `docs/team/` 或对应模块 README，然后删除计划书。

## 入库标准

计划书必须说明：

- 当前代码还缺什么。
- 目标行为是什么。
- 非目标是什么。
- 落地顺序。
- 完成后应沉淀到哪份规范或模块 README。

计划书不应保存历史争论、旧实现搬运清单或已经被当前代码替代的方案。
