Agent Browser Distillation

browser_interact 工作流与能力边界

这份报告描述从 agent-browser 蒸馏到当前 browser_interact 的核心能力：snapshot/ref、用户介入、运行时观测、iframe、tab、视觉定位、显式等待与下载触发观测。

2026-05-31
Overview

核心原则：让 LLM 操作页面，但不让页面控制 LLM

browser_interact 被收敛为一个结构化浏览器执行面。页面内容全部视为不可信输入；动作必须经由 schema、session、snapshot/ref 和策略边界进入浏览器。

Ref-first

先 snapshot，再使用精确 ref。禁止用 role、label、文本猜目标。

Runtime portable

headless、sandbox、dev_shm 通过配置注入，兼顾本地与沙箱。

User boundary

登录、验证码、敏感凭据、高风险行为进入用户介入通道。

Observable

status 暴露 dialog、console、pageerror、network、dom_version、tab 等低噪声摘要。

Recoverable

错误响应提供 category、code、retryable、recovery_hint 和 user_action，而不是裸异常。

Action Loop

一次浏览器动作的标准路径

tool 层只校验注入上下文；controller 做 action 分派；action runtime 统一拼装 session/page/runtime/error/success 响应。

1. Tool校验 session_id / user_id，复制 schema，注入启动选项。
2. Controller解析 action type，按 session 串行化，分派 handler。
3. Session校验 browser_session_id，创建或复用 Playwright page。
4. Action执行 navigate、snapshot、ref action、tab、wait、screenshot。
5. Response通过 build_response/error_factory 返回稳定 JSON。
action handler 内部不散落 response 组装逻辑，复杂错误通过 error_factory 归类，models 只保留 dataclass。
Snapshot / Ref

snapshot 是交互坐标系，不是正文抽取器

snapshot 生成可操作树和 refs；get_content 负责正文抽取。两条链路分工明确，避免把正文阅读和点击定位混在一起。

Ref 元数据

role/name/frame_path/frame_id/bounds/in_viewport 支持定位、iframe 解析、overlay 截图和错误诊断。

Scoped snapshot

snapshot(ref=eN) 可对已知子树局部展开，减少复杂页面噪声。

Focused snapshot

mode=focused + goal 用于找复杂页面中的具体控件。

Ref 失效

navigate、click、scroll、key、tab 切换等动作后保守失效，要求 fresh snapshot。

Safety

用户介入策略前置到真实动作之前

高风险点击和敏感输入不是执行后提醒，而是在 click/fill 之前阻断并返回 USER_INTERVENTION_REQUIRED。

信号触发来源工具行为用户动作
auth_pageURL / DOM 登录验证信号停止自动操作用户在可见浏览器完成登录或验证
captchareCAPTCHA / hCaptcha / Turnstile / 文本信号停止自动操作用户完成验证码
secret_inputpassword / OTP / token / API key 字段fill 前阻断用户手动输入敏感凭据
high_risk_action删除、支付、购买、转账、退款、退订等click 前阻断用户确认或手动完成
Observability

status 是诊断面，不是另一个执行入口

status 汇总低噪声运行态，帮助判断页面空白、脚本错误、网络错误、dialog、DOM 变化和多 tab 状态。

dialog

alert/beforeunload 自动处理；confirm/prompt 自动 dismiss 并记录。

network

记录 failed request、4xx/5xx、主文档状态码，URL query 脱敏。

dom_version

MutationObserver 记录 DOM 变化版本，辅助判断是否刷新 snapshot。

tabs

显式 list/switch/new/close tab，并在切换后让 refs 失效。

Content

get_content 补回 HTML 到 Markdown 能力

删除 web_fetch.content_processor 依赖后，browser_interact 本地使用 trafilatura 处理 HTML。空结果直接返回空，不做规则 fallback。

Rendered first

优先读取浏览器渲染后的正文文本，适配 SPA 和动态页面。

HTML markdown

需要时使用 trafilatura 做 HTML -> Markdown，避免回接 web_fetch。

Trust boundary

snapshot 和 get_content 均标记 untrusted_page_content，页面内容永远不是系统指令。

Action Surface

能力面按真实浏览器工作流组织

不加入 upload/download 文件接管；下载只观测触发事件，后续交给沙箱同步临时文件。

navigate / go_back / go_forward snapshot / get_content / screenshot click_ref / fill_ref / select_ref / check_ref scroll / key / wait wait_for_ref / wait_for_text new_tab / list_tabs / switch_tab / close_tab clear_browser_events

Overlay screenshot

screenshot(annotate_refs=true) 在截图上标出当前 refs，视觉状态和 snapshot 坐标可对齐。

Download trigger only

click_ref(expect_download=true) 只返回 download_triggered 和 suggested_filename，不处理文件路径。

Quality Gates

最终约束和验证结果

本轮不再继续蒸馏没有明确落地价值的能力；剩余高风险项已经通过边界设计规避。

编译

uv run python -m compileall 覆盖 browser、container、tool_settings。

静态扫描

无相对导入、无 Union、无 PEP585 泛型、无 urls、无 web_fetch content_processor 回流。

工具烟测

用户介入、iframe refs、tab、overlay、network、wait、download trigger 均通过。

明确未做：upload、下载文件接管、跨 tool call 事后确认 dialog、规则驱动 get_content fallback。
