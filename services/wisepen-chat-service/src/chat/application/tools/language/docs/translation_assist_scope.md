# Translation Assist 能力边界说明

本文档说明 `language` 工具体系中翻译辅助能力的当前边界。

## 当前定位

`translation_assist` 目前只作为模型自身翻译能力的 baseline 对照工具，不是完整翻译系统。

当前支持范围：

1. 高频中英互译。
2. 长文本分段后调用 OPUS-MT / MarianMT 生成机器翻译 baseline。
3. 给模型提供可参考的机器翻译结果，由模型结合上下文进行最终润色。

## 支持语言

当前仅支持：

1. `zh -> en`
2. `en -> zh`

tool schema 只允许 `source_language` 和 `target_language` 为 `zh` 或 `en`，且两者不能相同。

## 不支持范围

当前不支持：

1. 中文、英文之外的语言互译。
2. 多语种自动检测和路由。
3. 专业翻译记忆库。
4. 术语库强约束翻译。
5. 文学、法律、医学等高风险领域的独立最终译文生成。
6. 作为唯一翻译结果直接交付给用户。

除中英互译 baseline 外，其余翻译需求依赖模型自身能力完成。

## 使用原则

1. 需要中英互译且希望获得机器翻译对照时，可以调用 `translation_assist`。
2. 模型必须把工具输出视为 baseline，而不是最终答案。
3. 最终翻译应由模型结合上下文、语气、术语和用户要求自行润色。
4. 非中英翻译不应调用该工具，直接依赖模型自身翻译能力。

## 后续扩展条件

只有在出现明确高频需求且有稳定模型或词表支持时，才考虑扩展更多语言或术语能力。扩展时应继续保持 baseline 定位，避免把辅助工具误用为完整翻译平台。
