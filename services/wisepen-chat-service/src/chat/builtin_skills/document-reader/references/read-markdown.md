# Linux 下分段阅读 Markdown

使用转换回执中的相对路径。标题搜索用于定位，精确结论要读相关连续原文。

## 找到文件

已知转换输出就直接用该路径。如果需要在多个候选里查主题，限定产物目录，先列文件名。

```bash
rg --files 'reading' -g '*.md'
rg -l -g '*.md' -F -- '关键词' 'reading'
```

## 从标题或命中回到原文

```bash
md='reading/report.md'
rg -n -m 60 -- '^#{1,6}[[:blank:]]+' "$md"
rg -n -F -m 12 -C 3 --max-columns 240 --max-columns-preview -- '关键词' "$md"
awk 'NR >= 128 { printf "%d:%s\n", NR, $0 } NR == 176 { exit }' < "$md"
```

- 结果太多时，按标题层级、不同关键词或行范围缩小。搜索命中为空时结合目录、同义词及上下文判断。围栏代码内可能出现井号，Setext 标题位于下划线之前一行。
- 一个小节延续到下一同级或更高层级标题。读取表格时包含表头，代码和公式读到闭合标记，引用和脚注按需查看定义。
- 如返回 `output_truncated`、预览或省略标记，按更短的行段继续。遇到单行过长，仅查看相关字符范围。整份总结逐段覆盖相关正文和附录。
- 转换 Markdown 的行号用于定位中间产物。需要原件页号、幻灯片序号或单元格坐标时，按格式指南核对。

例如，三级标题位于第 128 行，下一个三级或更高标题位于第 177 行，连同下属四级标题读取 128 至 176 行。用下面的命令找边界。小文件可以读完，长章节拆成多个连续行段。

```bash
rg -n -- '^#{1,3}[[:blank:]]+' "$md"
rg -n -F -e '术语全称' -e '缩写' -- "$md"
rg -n -U -- '关键词一\s*关键词二' "$md"
```

最后一条用于跨行模式匹配。字面搜索优先用 `-F`。超长单行可先用 `--max-columns-preview` 找位置，再按字符范围取正文。核查遗漏时继续检查同义表达、示例、附录和关联段落。跨文件对比时，每条结论保留源文件名与足以复查的位置。
