# 1. 历史事件箭头时间线（单独成章）

使用方法：先沿箭头判断题目属于哪一段历史，再回到“教材页码定位总表”和对应章节。箭头后的说明不是废话，是帮助你把事件串成论述题逻辑。

## 1840-1919：从被迫开国到旧民主主义革命终结

1840 鸦片战争爆发 → 1842《南京条约》 → 1851 太平天国兴起 → 1856 第二次鸦片战争 → 1861 洋务运动起步 → 1894 甲午战争 → 1895《马关条约》 → 1898 戊戌维新 → 1900 八国联军侵华 → 1901《辛丑条约》 → 1905 同盟会成立 → 1911 武昌起义 → 1912 中华民国成立 → 1915 新文化运动 → 1919 五四运动

• 这条线的核心是“民族危机不断加深—不同力量先后探索—旧道路不能完成反帝反封建任务”。

• 鸦片战争和《南京条约》开启半殖民地半封建化进程；《马关条约》后列强争夺势力范围；《辛丑条约》后清政府完全成为列强统治中国的工具。

• 太平天国、洋务、维新、辛亥都应放在“早期探索”框架下评价：有进步性，但受阶级局限，不能根本改变中国命运。

## 1919-1949：从新民主主义革命开端到新中国成立

1919 五四运动 → 1921 中共一大 → 1922 中共二大 → 1924 第一次国共合作 → 1925 五卅运动 → 1926-1927 上海工人三次武装起义/北伐 → 1927 四一二反革命政变 → 1927 南昌起义/八七会议/秋收起义 → 1928 井冈山会师 → 1929 古田会议 → 1935 遵义会议 → 1935 瓦窑堡会议 → 1936 西安事变和平解决 → 1937 七七事变/洛川会议 → 1938《论持久战》 → 1940 百团大战 → 1942 延安整风 → 1945 中共七大/抗战胜利/重庆谈判 → 1946 全面内战 → 1947 土地改革和第二条战线 → 1948-1949 三大战役 → 1949 七届二中全会/渡江战役/政协会议/新中国成立

• 这条线的核心是“党的成立—革命道路探索—抗日民族统一战线—人民解放战争—人民民主专政新中国”。

• 五四运动是新民主主义革命开端；中共成立使中国革命有了坚强领导核心；井冈山道路解决“怎样革命”；遵义会议解决危急关头党的领导和路线问题。

• 抗战论述题要把“全民族抗战”和“中国共产党中流砥柱”结合，不要把正面战场和敌后战场割裂。

## 1949-1978：从新中国成立到社会主义建设探索

1949 新中国成立 → 1950 土地改革/抗美援朝 → 1953 过渡时期总路线 → 1954 第一届全国人大/第一部宪法 → 1956 三大改造基本完成/社会主义基本制度确立/中共八大 → 1958 大跃进和人民公社化运动 → 1961-1965 国民经济调整 → 1964 四个现代化目标提出 → 1966-1976 “文化大革命” → 1976 粉碎“四人帮” → 1978 真理标准问题讨论/十一届三中全会

• 这条线的核心是“站起来—制度确立—探索建设—曲折中前进—转向改革开放”。

• 第八章不能只背“三大改造”，还要会说明新中国巩固政权、工业化起步、社会主义制度确立和建设探索成就。

• 评价探索时期要按教材口径：既看到“大跃进”“文化大革命”等严重曲折，也看到工业体系、国防科技、外交和社会建设成就。

## 1978-2012：改革开放与中国特色社会主义开创发展

1978 十一届三中全会 → 1978-1984 农村改革/家庭联产承包责任制 → 1980 经济特区设立 → 1982 中共十二大 → 1987 中共十三大/社会主义初级阶段基本路线 → 1992 南方谈话/中共十四大 → 1997 中共十五大/香港回归 → 1999 澳门回归 → 2002 中共十六大 → 2007 中共十七大 → 2012 中共十八大

• 这条线的核心是“伟大转折—改革开放起步—社会主义市场经济—跨世纪发展—科学发展”。

• 十一届三中全会是历史转折；南方谈话回答姓资姓社、计划市场等关键问题；中共十四大确立社会主义市场经济体制改革目标。

• 第九章选择题很多来自会议：十二大“建设有中国特色的社会主义”；十三大“初级阶段理论和基本路线”；十四大“市场经济”；十五大“邓小平理论”。

## 2012-2022及以后：中国特色社会主义进入新时代

2012 中共十八大 → 2017 中共十九大/新时代重大判断/习近平新时代中国特色社会主义思想确立为指导思想 → 2020 完成新时代脱贫攻坚目标任务 → 2021 全面建成小康社会/建党百年/十九届六中全会第三个历史决议 → 2022 中共二十大/以中国式现代化全面推进中华民族伟大复兴

• 这条线的核心是“新时代—新思想—全面小康—百年经验—中国式现代化”。

• 选择题要区分：十八大以来进入新时代；十九大作出中国特色社会主义进入新时代的重大政治判断；二十大聚焦中国式现代化全面推进民族复兴。

• 论述题若考中国式现代化，要回扣近代以来民族复兴主线：民族独立是前提，社会主义制度是基础，改革开放是动力，新时代是新阶段。

• 条约题排除法：看到“割香港岛”选《南京条约》；看到“允许设厂”选《马关条约》；看到“使馆界/驻兵/禁止反帝”选《辛丑条约》。

• 半殖民地半封建化进程可按三步记：开始形成（鸦片战争后）→ 大大加深（甲午后）→ 基本形成（《辛丑条约》后）。

• “协定关税”破坏关税自主权；“领事裁判权”破坏司法主权；“租界/使馆界/驻兵”破坏领土与行政主权。

## A.9 选择题复习法：三轮扫表，不再散着背

• 第一轮：只背 A.1 年份表和 A.7 标志词表。目标是看到年份能想到事件，看到“开端/转折/确立”能想到唯一答案。

• 第二轮：背 A.2 条约表和 A.3 会议表。目标是把“内容—会议/条约”反向对应起来，例如“允许设厂→马关”，“市场经济目标→十四大”。

• 第三轮：背 A.4 人物文献、A.5 运动战争、A.6 上海地点。目标是处理题干里出现人名、书名、地点、运动名称的题。

• 最后十分钟：扫 A.8 易错判断。选择题真正扣分点往往不是完全不会，而是把相近事件混了。

## 一、考前总抓手：所有学习思考题背后的共同逻辑

• 原因题：按“时代背景/社会性质 → 阶级力量 → 思想理论 → 组织路线 → 群众基础”展开。不要只背结论，要说明为什么这个结论在当时必然出现。

• 意义题：按“对当时的直接作用 → 对历史进程的推动 → 对民族复兴主线的贡献 → 对今天的启示”展开。

• 失败教训题：不要写成“完全没意义”。标准写法是“肯定历史作用，同时指出阶级局限、路线局限、群众基础不足、制度局限”。

• 比较题：先定性质，再比领导力量、纲领目标、群众动员、斗争方式、结果影响。

• 新时代题：不要空喊口号，必须把“社会主要矛盾变化、五位一体、四个全面、新发展理念、中国式现代化、民族复兴”连起来。

## 第一章 进入近代后中华民族的磨难与抗争｜学习思考题详解

教材学习思考出现位置：教材 p.46｜PDF p.60。本章答题时优先围绕“历史任务—阶级力量—道路选择—民族复兴主线”组织。

### 1. 为什么说鸦片战争是中国近代史的起点？

定位页码： 第一章第一节 p.16-23；第四节 p.41-46｜PDF p.30-37、p.55-60

考场抓手： 抓“社会性质变了、主要矛盾变了、革命任务变了、世界联系变了”。

详细解读

• 鸦片战争以前，中国总体上仍是独立的封建国家；战后《南京条约》及后续条约破坏领土、关税、司法等主权，中国开始被纳入资本主义世界殖民体系。

• “近代史开端”的关键不只是战争失败，而是中国开始由封建社会逐步变成半殖民地半封建社会。半殖民地表现为主权不完整，半封建表现为自然经济逐步解体但封建剥削仍占优势。

• 主要矛盾发生变化：帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾成为近代中国基本矛盾。

• 历史任务发生变化：争取民族独立、人民解放成为首要任务；实现国家富强、人民幸福成为延续性目标。

可用案例

• 1842《南京条约》：割香港岛、五口通商、赔款、协定关税。

• 1843《虎门条约》及《五口通商章程》体系：片面最惠国、租地建屋、领事裁判权。

• 魏源《海国图志》提出“师夷长技以制夷”，说明先进中国人开始睁眼看世界。

可直接落笔： 鸦片战争之所以成为中国近代史起点，是因为它不是一次普通战败，而是使中国社会性质、主要矛盾和历史任务发生系统性变化。此后，中国人民既要反对封建压迫，又要反对外国侵略，民族独立和人民解放成为近代中国的首要主题。

### 2. 资本-帝国主义的入侵给中国带来了什么？

定位页码： 第一章第二节 p.23-33｜PDF p.37-47

考场抓手： 按“军事侵略、政治控制、经济掠夺、文化渗透”四类写，结论是灾难深重，不能美化侵略。

详细解读

• 军事上，列强发动一系列侵华战争，屠杀人民、割占土地、勒索赔款，使中国不断遭受战争破坏。

• 政治上，通过不平等条约、领事裁判权、使馆界、驻兵权等控制中国内政外交。

• 经济上，通过协定关税、通商口岸、商品倾销、资本输出和在华设厂，破坏中国经济主权并压迫民族工业。

• 文化上，列强利用传教、报刊、学校等进行文化渗透，服务其侵略秩序。

• 必须把握教材立场：侵略客观上刺激中国自然经济解体、促使少数先进中国人反思，但不能由此说“侵略促进中国发展”；其本质是阻碍中国独立发展。

可用案例

• 第二次鸦片战争中英法联军火烧圆明园。

• 《马关条约》允许日本在通商口岸设厂，标志资本输出加深。

• 《辛丑条约》划使馆界、允许驻兵、禁止反帝组织，清政府成为列强统治中国的工具。

可直接落笔： 资本-帝国主义入侵给中国带来的首先是民族灾难和主权破坏。它通过军事侵略、政治控制、经济掠夺和文化渗透，使中国逐步沦为半殖民地半封建社会，严重阻碍了中国独立发展。

### 3. 反对外国侵略的斗争具有什么意义？

定位页码： 第一章第三节 p.35-40；第四节 p.44-46｜PDF p.49-54、p.58-60

考场抓手： 既写“直接抵抗”，又写“民族意识觉醒”。

详细解读

• 近代反侵略斗争体现了中国人民不甘屈服的民族气节，保存和发展了中华民族反抗外侮的精神传统。

• 虽然多次战争失败，但人民群众、爱国官兵和先进知识分子的抗争，打击了列强瓜分中国的图谋。

• 反侵略斗争推动民族意识觉醒，促使先进中国人思考国家出路，从器物学习到制度变革，再到革命道路探索。

• 它为后来救亡图存运动提供精神资源，也证明民族独立是现代化的前提。

可用案例

• 三元里人民抗英是近代中国人民群众第一次大规模反侵略武装斗争。

• 邓世昌、林永升等甲午海战爱国将领体现民族气节。

• 义和团运动粉碎列强瓜分中国的图谋，但也有盲目排外局限。

可直接落笔： 反侵略斗争的意义不仅在于具体战斗胜负，更在于它体现了中华民族不屈服于外来压迫的精神，推动了民族意识觉醒，使救亡图存逐渐成为近代中国的时代主旋律。

### 4. 反侵略战争失败的根本原因和教训是什么？

定位页码： 第一章第四节 p.41-44｜PDF p.55-58

考场抓手： 教材标准答案：根本原因是社会制度腐败，重要原因是经济技术落后。

详细解读

• 社会制度腐败是根本原因。清政府昏庸腐败、害怕人民、妥协求和，不能有效组织全民抵抗。

• 经济技术落后是重要原因。工业、军事、交通、财政和组织能力落后，使中国在近代战争中处于不利地位。

• 不能简单理解为“武器落后必败”。教材强调武器重要但不是决定因素，决定因素是人和制度组织能力。

• 教训是：民族独立必须有先进社会制度、坚强政治领导、广泛人民动员和现代化综合国力。

可用案例

• 鸦片战争中林则徐、邓廷桢等被革职，妥协派受重用。

• 中法战争镇南关大捷后清政府仍“不败而败”。

• 甲午战争中清政府挪用海军经费、北洋舰队建设停滞。

可直接落笔： 近代反侵略战争失败，根本上不是中国人民没有抵抗精神，而是腐败的封建制度无法组织有效抵抗；经济技术落后则进一步放大了失败。其教训是，只有实现民族独立、制度变革和国家现代化，才能真正摆脱被动挨打。

## 第二章 不同社会力量对国家出路的早期探索｜学习思考题详解

教材学习思考出现位置：教材 p.66｜PDF p.80。本章答题时优先围绕“历史任务—阶级力量—道路选择—民族复兴主线”组织。

### 1. 如何认识太平天国农民战争的意义和失败的原因、教训？

定位页码： 第二章第一节 p.49-54｜PDF p.63-68

考场抓手： 意义：农民战争高峰；失败：农民阶级局限。

详细解读

• 太平天国沉重打击了清王朝统治和外国侵略势力，是近代中国规模巨大的农民战争。

• 《天朝田亩制度》否定封建土地所有制，表达农民对土地和平等的强烈要求，但平均主义方案带有空想性，难以实行。

• 《资政新篇》提出发展资本主义的若干主张，具有近代化因素，但脱离战争环境和农民实际，未能实行。

• 失败原因包括农民阶级不能提出科学纲领、宗教迷信和等级特权影响、领导集团内讧、无法正确处理与先进生产方式和民族独立的关系。

• 教训：单靠农民阶级自发反抗不能完成反帝反封建任务，必须有先进阶级、科学理论和坚强组织领导。

可用案例

• 1851 金田起义；1853 定都天京。

• 《天朝田亩制度》：“凡天下田，天下人同耕”。

• 天京事变削弱太平天国内部凝聚力。

可直接落笔： 太平天国是农民阶级反封建反侵略斗争的高峰，但农民阶级自身局限使其不能提出科学而可行的国家方案。它的失败说明，近代中国革命必须超越旧式农民战争，需要新的领导力量和新的理论指导。

### 2. 如何认识洋务运动的性质和失败的原因、教训？

定位页码： 第二章第二节 p.55-58｜PDF p.69-72

考场抓手： 性质：地主阶级自救；作用：早期现代化；失败：不触动封建制度。

详细解读

• 洋务运动是在内忧外患中，清朝统治集团内部洋务派为维护封建统治而进行的自救运动。

• 它主张“自强”“求富”，兴办军事工业、民用企业、新式学堂、派遣留学生、筹建海军，客观上开启中国早期现代化。

• 但洋务派坚持“中体西用”，只学西方器物技术，不改革封建政治制度，导致近代企业受官僚体制束缚。

• 失败还与洋务企业管理腐败、资金分散、军队制度落后、列强压迫有关。甲午战争中北洋海军失败宣告洋务运动破产。

• 教训：现代化不能只靠器物模仿，必须进行制度、思想、组织和社会结构的深层变革。

可用案例

• 曾国藩、李鸿章、左宗棠、张之洞为洋务派代表。

• 江南制造总局、福州船政局、轮船招商局、开平矿务局。

• 甲午战争中北洋舰队全军覆没。

可直接落笔： 洋务运动具有维护封建统治的性质，但客观上推动了中国早期工业、教育和军事近代化。它失败的根本原因在于不改变封建制度而试图用西方技术补救旧体制，说明器物层面的学习不能真正救中国。

### 3. 如何认识戊戌维新运动的意义和失败的原因、教训？

定位页码： 第二章第三节 p.59-66｜PDF p.73-80

考场抓手： 意义：制度变革和思想启蒙；失败：维新派软弱、守旧势力强、脱离群众。

详细解读

• 戊戌维新是资产阶级改良派推动的政治制度变革尝试，主张变法图强、发展资本主义、实行君主立宪。

• 它突破了洋务运动只学器物的局限，把救亡图存推进到制度层面，具有思想启蒙意义。

• 失败原因包括维新派力量弱小，缺乏坚强组织和武装力量；依靠没有实权的皇帝；脱离广大人民群众；对帝国主义和封建守旧势力抱有幻想。

• 教训：在半殖民地半封建中国，温和改良难以触动深层利益结构，不能承担彻底反帝反封建任务。

可用案例

• 1895 公车上书；康有为、梁启超宣传变法。

• 1898 百日维新；慈禧太后发动戊戌政变。

• 谭嗣同等“戊戌六君子”遇害。

可直接落笔： 戊戌维新把中国近代探索推进到制度变革层面，具有爱国救亡和思想启蒙意义。但维新派依靠少数上层力量，缺乏群众基础和反封建彻底性，最终失败，说明改良道路难以完成民族独立和国家富强任务。

## 第三章 辛亥革命与君主专制制度的终结｜学习思考题详解

教材学习思考出现位置：教材 p.89｜PDF p.103。本章答题时优先围绕“历史任务—阶级力量—道路选择—民族复兴主线”组织。

### 1. 革命派在与改良派论战中如何论述革命的必要性、正义性、进步性？

定位页码： 第三章第一节 p.75-77｜PDF p.89-91

考场抓手： 必要性反清，正义性反专制，进步性建共和。

详细解读

• 必要性：革命派认为清政府已成为帝国主义统治中国的工具，继续改良不能救亡，必须推翻腐朽政权。

• 正义性：革命不是制造混乱，而是反对专制压迫、争取民族独立和民主权利。革命暴力针对反动统治，而非破坏社会本身。

• 进步性：革命派主张建立资产阶级共和国，用民主共和制度替代君主专制，符合世界政治发展潮流。

• 论战推动民主革命思想传播，使更多人认识到清末新政和君主立宪无法根本解决民族危机。

可用案例

• 同盟会机关报《民报》与改良派报刊展开论战。

• 孙中山在《民报》发刊词中阐发民族、民权、民生三民主义。

• 清末“预备立宪”被证明维护皇族和权贵利益。

可直接落笔： 革命派通过同改良派论战，说明推翻清王朝具有救亡图存的必要性、反对专制的正义性和建立共和的进步性。这场论战促进了民主革命思想传播，为辛亥革命作了思想准备。

### 2. 为什么说孙中山领导的辛亥革命引起了近代中国的历史性巨大变化？

定位页码： 第三章第二节 p.77-82；第三节 p.85-89｜PDF p.91-96、p.99-103

考场抓手： 三层：推翻清朝、结束君主专制、传播共和观念。

详细解读

• 政治制度上，辛亥革命推翻清王朝，结束了中国两千多年的君主专制制度。

• 国家形式上，建立中华民国，颁布《中华民国临时约法》，使共和国方案成为现实尝试。

• 思想观念上，民主共和观念深入人心，复辟帝制不得人心。

• 社会生活上，推动剪辫、易服、兴女学、改称谓等社会风气变化，并促进民族资本主义发展。

• 历史接续上，辛亥革命打开进步潮流，但未完成任务，后来中国共产党继承和发展孙中山革命事业。

可用案例

• 1911 武昌起义；1912 中华民国临时政府成立。

### 1. 联系我国社会主要矛盾的新变化，如何理解中国特色社会主义进入新时代的内涵和意义？

定位页码： 第十章第一节 p.312-318｜PDF p.326-332

考场抓手： 新时代判断+主要矛盾变化+民族复兴新阶段。

详细解读

• 中国特色社会主义进入新时代，是我国发展新的历史方位。党的十八大以来进入新时代，党的十九大作出重大政治判断。

• 社会主要矛盾变化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。

• 这一变化说明我国已经解决温饱并总体小康，人民需求从物质文化需要扩展到民主、法治、公平、正义、安全、环境等方面。

• 但我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，世界最大发展中国家的国际地位没有变。

• 意义在于中华民族迎来从站起来、富起来到强起来的伟大飞跃，科学社会主义在21世纪中国焕发生机。

可用案例

• 全面建成小康社会、脱贫攻坚体现人民生活水平提升。

• 五位一体总体布局回应经济、政治、文化、社会、生态多方面需求。

• 新发展理念回应不平衡不充分发展问题。

可直接落笔： 新时代的内涵，核心是我国发展站到新的历史方位，社会主要矛盾发生关系全局的变化。它标志着中华民族伟大复兴进入关键阶段，也要求党和国家更加注重解决发展不平衡不充分问题，满足人民美好生活需要。

### 2. 联系实际，谈谈党的十八大以来党和国家事业发生了怎样的历史性变革，其意义是什么。

定位页码： 第十章第一、二、三节 p.312-401｜PDF p.326-415

考场抓手： 可按“五位一体+四个全面+风险挑战+小康脱贫”组织。

详细解读

• 经济建设上，贯彻新发展理念，推动高质量发展，构建新发展格局。

• 政治建设上，坚持党的全面领导，推进国家治理体系和治理能力现代化，发展全过程人民民主。

• 文化、社会、生态上，增强文化自信，改善民生，推进脱贫攻坚和生态文明建设。

• 国家安全、国防外交上，加强总体国家安全观，推进国防和军队现代化，推动构建人类命运共同体。

• 全面从严治党上，以自我革命引领社会革命，党在革命性锻造中更加坚强。

• 意义在于为实现中华民族伟大复兴提供更完善制度保证、更坚实物质基础、更主动精神力量。

可用案例

• 脱贫攻坚战取得全面胜利。

• 全面深化改革、全面依法治国、全面从严治党深入推进。

• 抗击重大风险挑战、推进生态文明建设、共建“一带一路”。

可直接落笔： 党的十八大以来的历史性变革，体现在经济、政治、文化、社会、生态、国防、外交和党的建设各方面。这些变革使党和国家事业取得历史性成就，为实现中华民族伟大复兴提供了更坚实基础。

### 3. 联系历史和现实，谈谈全面建成小康社会的历史意义。

定位页码： 第十章第三节 p.379-389｜PDF p.393-403

考场抓手： 中华民族千年梦想、百年奋斗目标、共同富裕基础。

详细解读

• 小康社会承载着中华民族长期追求的生活理想，全面建成小康社会意味着这一梦想在中国共产党领导下成为现实。

• 它标志着第一个百年奋斗目标实现，为开启全面建设社会主义现代化国家新征程奠定基础。

• 脱贫攻坚全面胜利，历史性解决绝对贫困问题，体现社会主义制度优势和人民立场。

• 全面小康不是少数人的小康，而是覆盖十几亿人口、区域城乡整体推进的小康。

• 它增强民族自信，为中国式现代化和共同富裕提供新的历史起点。

可用案例

• 2020 完成新时代脱贫攻坚目标任务。

• 2021 庆祝中国共产党成立100周年大会宣告全面建成小康社会。

• 脱贫攻坚体现精准扶贫、东西部协作、基层党组织动员。

可直接落笔： 全面建成小康社会的历史意义在于，它实现了中华民族千百年来的小康梦想，完成第一个百年奋斗目标，历史性解决绝对贫困问题，为全面建设社会主义现代化国家奠定坚实基础。

### 4. 如何理解“两个确立”的决定性意义？

定位页码： 第十章第一节 p.315-318；第二节 p.342-347；第三节 p.396-410｜PDF p.329-332、p.356-361、p.410-424

考场抓手： 两个确立：确立习近平同志党中央核心、全党核心地位；确立习近平新时代中国特色社会主义思想指导地位。

详细解读

• “两个确立”是新时代党和国家事业取得历史性成就、发生历史性变革的重要政治成果。

• 确立核心，是马克思主义政党成熟的重要标志，有利于维护党中央权威和集中统一领导。

• 确立思想指导地位，有利于全党全国人民在新时代新征程上统一思想、统一意志、统一行动。

• 其决定性意义体现在应对复杂风险挑战、推进中国式现代化、实现中华民族伟大复兴需要坚强领导核心和科学理论指导。

• 答题要注意与“两个维护”区分：两个确立是政治成果和历史结论；两个维护是实践要求。

可用案例

• 十九大将习近平新时代中国特色社会主义思想确立为党的指导思想。

• 十九届六中全会总结新时代历史性成就和历史经验。

• 二十大对中国式现代化全面推进民族复兴作出战略部署。

可直接落笔： “两个确立”具有决定性意义，是因为新时代坚持和发展中国特色社会主义、推进中华民族伟大复兴，必须有坚强领导核心和科学理论指导。它为全党全国人民在复杂形势下团结奋斗提供根本政治保证和思想指引。
